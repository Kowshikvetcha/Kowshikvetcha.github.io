# Kowshik Vetcha — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript — no build step.

- **Edit content:** everything on the page comes from [`content.js`](content.js).
- **Run locally:** `python -m http.server 5173` and open http://localhost:5173
- **Deploy:** pushing to `main` publishes via GitHub Pages.
- **Contact form:** delivered by [Web3Forms](https://web3forms.com); the public access key lives in `content.js`.
